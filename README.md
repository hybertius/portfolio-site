# Victor's portfolio

A simple, responsive portfolio for introducing Victor and showcasing a selection of web projects.

**[View the portfolio on GitHub Pages](https://hybertius.github.io/portfolio-site/)** once GitHub Pages is enabled for this repository.

## What's inside

- An introduction and a selection of project cards.
- A responsive layout for desktop and mobile.
- Light and dark themes, with a manual toggle and system preference support.
- Reduced-motion support.

The site is built with HTML, CSS, and JavaScript in a single `index.html` file. No build step or dependencies are required.

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Push the repository to GitHub.
2. In the repository, open **Settings > Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `master` branch and the `/ (root)` folder, then save.

After GitHub Pages deploys the site, it should be available at the link above. If you publish from a different account or repository, update the link to match its GitHub Pages URL.
