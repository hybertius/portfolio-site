# Victor's portfolio

A simple, responsive portfolio for introducing Victor and showcasing a selection of web projects.

**[View the portfolio on GitHub Pages](https://hybertius.github.io/portfolio-site/)**

## What's inside

- An introduction and a selection of project cards.
- A responsive layout for desktop and mobile.
- Light and dark themes, with a manual toggle and system preference support.
- Reduced-motion support.

The site is built with HTML, CSS, and JavaScript in a single `index.html` file. No build step or dependencies are required.
